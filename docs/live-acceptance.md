# 正式工作台验收记录

验收日期：2026-09-09。实施范围为 `agent.md` 的 PRD V0.2，视觉采用用户指定的暖纸设计系统。运行入口为本项目，浏览器端默认 `http://127.0.0.1:5174/events`。

## 已完成的业务链路

- 空库配置 RSS/Atom → 实际测试连接 → 保存/启停 → 手动获取 → 精选/全部/收藏 → 材料与原文 → 个人判断保存 → 刷新后回看。
- 播客/长视频订阅 → 选择至少一个启用频道 → 手动元数据研究 → 持久化任务与结果 → 从任务跳转到对应事件。
- 部分失败、全失败、手动重试未完成信源；成功内容和最后成功时间保留。关闭中的任务与启动时遗留任务标记中断。
- 原每日早报、正在关注页面和个人原型笔记保留；演示内容不进入正式新闻数据库。

## 浏览器实际操作

使用 Tabbit，配合 `node tests/ui-server.js` 的独立临时数据库和 HTTP 受控 RSS。样本标题明确标记「测试数据」。完成以下验证：

- 初始空态、真实订阅测试、保存；失败测试显示 HTTP503 并保留表单输入。
- 手动获取显示10条精选；全部列表12条；首次历史载入无全量增量标记。
- 收藏、刷新恢复、取消收藏后笔记保留；搜索和分类组合、空态重置、范围切换清理详情。
- 1440×900 布局：150px 导航、400px 详情；打开详情后列表 scrollTop 仍为450。页面没有横向溢出。
- 390×844 抽屉：原文、收藏与笔记可达；Escape关闭；页面宽度390，无横向溢出。
- 注入一次保存503：草稿保留、错误可见，取消注入后重试成功。
- 另一窗口更新同一笔记：409展示另一版本，保留草稿，显式载入版本后重新保存。
- 开始编辑后触发后台获取刷新，再保存仍检测旧版本冲突；草稿不会静默覆盖另一窗口。
- 频道未选中时禁止启动；选中后运行，完成结果已入库且能从设置直接跳转到唯一事件。
- 部分失败列出成功与失败信源；重试仅请求失败源，缓存仍可读。
- OPML FilePayload 导入4个额外信源；同事件聚合为5篇材料/5个独立来源，长材料列表弹窗实际展示5项。

修复并复验：研究完成时结果入口原先随折叠详情隐藏，现设置中的任务默认展开。自动化对异步启停控件的即时断言曾提前失败；读取最新状态确认已成功停用后继续，没有重复提交。

复制补充验证：自动测试覆盖实际生成的标题、摘要、具体原文地址及缺失地址提示，确保不包含个人判断；覆盖剪贴板拒绝和权限悬置超时。浏览器点击复制后的系统剪贴板读取等待权限，自动化读回未完成，因此不宣称系统剪贴板读回验收通过；生产复制等待超过5秒会报告未完成，不会假报成功。Tabbit 隔离该悬置请求后执行了一次结束操作；运行时报告需要强制断开清理，未能按保留模式保存测试标签。没有切换浏览器绕过权限。

## 范围与限制

- 研究工具是实际可用的元数据整理，不含音视频转录、全文浏览或外部模型。个人判断不会发送给研究工具。
- 未提供的 SoPilot、Investing.com 和播客清单仍由用户在设置里配置；不猜测订阅地址。
- 标题聚合为保守启发式，不能代替语义验证。缺少 URL/GUID 的相同标题条目可能归为同一材料。
- 未保存草稿只在当前工作台内存保留；关闭进程不能保证恢复。正式保存的数据写入 SQLite。
- 一个数据目录应只运行一个服务实例；浏览器与桌面默认使用不同目录。
- 自动日报/周报、定时抓取、复杂分析、外部模型和独立安装包发布没有混入本次 V0.2 交付。
