# Signal Desk 原型前端交付

> 本文记录原型转换阶段；正式工作台现以 `/events` 为默认入口，支持真实抓取与频道研究。实际架构和接口以 `agent.md` 为准，验收见 `live-acceptance.md`。

## 设计与工程依据

实施入口为本项目 `daily-news/`，上级保留旧原型。本次参考用户提供的上级 `front-desgin/DESIGN.md` 与 14 个页面的 `code.html`、`screen.png`；没有修改原件。运行和构建不读取相邻目录。

原规范包含两套同名 token。第一套和 HTML 实际配置一致：`primary #8f482f`、`canvas #faf9f5`、`ink #141413`、`surface-card #efe9de`、`hairline #e6dfd8`，故采用第一套；不混用历史 alpha 的 `primary #cc785c`。HTML 个别按钮的橙色表现与规范不一致，以规范为准。

`src/client/data/theme.json` 为实际构建 token；`tailwind.config.js` 提供色系、字阶、间距、圆角。`style.css` 通过 `theme()` 使用颜色。英文展示字体 EB Garamond，正文 Inter，数字 JetBrains Mono；中文使用系统字体。字体本地打包，Lucide 图标为 SVG。无复杂阴影，保持纸色分层、细线分隔、紧凑侧栏及正文层级。

沿用 Vite + Node + Electron，前端升级 React + React Router，生产服务提供 History 路由回退。未引入 Next.js 服务，避免更换既有 SQLite 和桌面生命周期。

## 组件职责

- `Layout`：顶部栏、全局搜索、主题切换、本地状态、演示标记与页面插槽。
- `Sidebar`：导航分组、路由选中态、收藏计数、实际服务健康状态；窄屏菜单。
- `IntelligenceCard`：日报/信息流两种变体，共享稳定 ID、正文、书签、研读入口。
- `Drawer`：文章内容、原型信源标记、笔记与导出、完成研读；原生 dialog、遮罩、Escape、焦点恢复与 Tab 循环。
- `state.jsx`：读取本地记录、按序写入 SQLite、待保存队列和失败重试。记录在组件之间共享。

## 数据与交互边界

`issues.json` 从日报原型脚本逐字提取 3 期（9 月 6–8 日）、6 篇文章及速览。`intelligence.json` 从正在关注原型提取 8 篇卡片正文。`references.json` 保留全部 14 页文本，`public/prototypes/` 保留截图，不执行原型内联脚本。

新增的主题关联、排序字段与界面评分用于演示筛选，均不是实时数据。原型“142 期”“50 个信源”等统计保留为明确标注的原型统计；实际列表只对已有内容分页，不复制文章凑数。

原型里曾存在只做提示、反转数组或按奇偶隐藏卡片的交互，本轮改为真实字段筛选排序、文件下载和本地保存。未提供正文的归档显示空态；缺少 URL 的信源显示不可跳转。未伪造抓取、译文、外网同步或交叉核验成功。

SQLite `workspace_entries` 以文章稳定 ID 或 `preferences` 为主键。写入 API 校验类型、500 字笔记上限、配置长度/数量，拒绝非 JSON 和跨域写入。个人记录与正文分离，失败保留页面待存改动。多窗口同一文章并发编辑尚无冲突合并。

信源管理支持配置草稿、保存、启停、权重、新增/编辑/移除、OPML 导入/导出；启停和权重作用于当前演示卡片。RSS 抓取和网络健康巡检未接入。
