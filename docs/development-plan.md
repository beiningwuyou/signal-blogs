# Signal Desk 完整开发方案与验收清单

依据：`agent.md` 的 PRD V0.2 功能要求，以及用户指定的暖纸设计原型。实施保持现有 React/Vite/Node/SQLite/Electron；不重建工程、不混入上级旧原型数据。

## 需求取舍与边界

业务以 `agent.md` 为准；视觉遵守用户更早明确要求的 `DESIGN.md` 暖纸色系、细线和无复杂阴影。正式工作台使用中文标签，无英文装饰副标题，1440×900 时约 150px 导航、弹性列表、400px 详情。默认精选，原有高保真原型独立保留为演示入口及设计参考，原型笔记保持原 ID。

PRD 明确列为 Later 的自动日报/周报、定时获取、复杂分析，和排除的账号、收费、外部通知不因原型存在而自动加入。日报、周刊等原型不冒充真实业务；若用户追加扩大范围，再更新本方案。原始播客候选与具体 SoPilot/Investing.com feed 尚缺少，提供可配置入口，不臆造订阅地址。

## 架构

- 同一个 Node 服务提供 REST、静态资源及 SQLite；前端沿用 React hooks 和同源 fetch 包装，不另加状态框架。
- `src/server/db.js` 为数据库入口；迁移版本化且只增表/列，迁移前使用 SQLite 一致性备份，原 `workspace_entries` 保留。
- `src/server/ingestion/` 管理受限网络读取、RSS/Atom 解析、标准化；抓取文本不执行 HTML/脚本，不任意读取私网服务。
- 持久化 sources、materials、events、event_materials、event_changes、event_records、jobs、job_sources。任务与单信源结果先入库，完成必须有持久化结果。
- 任务运行与 HTTP 请求分离，返回任务 ID 后执行受限并发抓取，界面轮询；退出取消未完成请求并将任务标记中断，可手动重试。禁止默认触发模型研究。
- 记录 PATCH 按字段更新；笔记带版本冲突检查，收藏不会覆盖笔记。个人判断永不进入研究输入。
- 工具提供实际可运行且无需密钥的元数据研究，明确显示输入范围、逐信源失败与结果。当前没有外部模型配置；PRD 允许元数据方式，外部模型不作为本轮新增范围。个人判断不进入研究输入。
